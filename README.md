# FCE Trainer

Тренажёр для подготовки к Cambridge B2 First (FCE).

**Открыть:** https://kozypot.github.io/fce-trainer/

- **Слова** — словарь B2 от A до Z, Upgrade (простое → сильное) и слова из тетради. Карточки со свайпами, тесты, интервальное повторение, работа над ошибками.
- **Reading & Use of English** — все 7 частей в формате экзамена, с таймером и объяснением каждого ответа.
- **Writing** — шпаргалки по 6 форматам и тренировка письма с таймером на 40 минут и счётчиком слов.
- **Прогресс** — стрик, дневная цель в XP (в Reading XP начисляются по баллам Cambridge) и достижения.

Прогресс хранится в браузере (localStorage). Сайт статический, без сборки: `index.html`, `style.css`, `app.js` и `data/*.json`.
